# AML-INVESTIGATOR
Hệ thống multi-agent hỗ trợ tự động hóa phần điều tra sau khi một cảnh báo AML được tạo. Hệ thống kết hợp phân tích giao dịch, đồ thị quan hệ, hồ sơ KYC, UBO, sanctions/PEP screening, thư viện AML typology và quy định nội bộ để xây dựng một bộ hồ sơ điều tra có bằng chứng trước khi chuyển cho chuyên viên AML phê duyệt.
